# XParallel Workspace V2\n\nWorkspace V2 turns the standalone XParallel interface into the working control surface for parallel development.\n\n## Workspace areas\n\n- **Overview** — live gateway state and solution intake.\n- **Projects** — current Axaliai workspace and architecture.\n- **Solutions** — live workspace-scoped solution records.\n- **Agents** — Planner, Builder, Tester and Verifier roles.\n- **Sandbox** — controlled execution boundary and approval status.\n- **Evidence** — verification and traceability boundary.\n- **Graph** — safe public workspace graph search.\n- **Deploy** — human-approval-controlled release boundary.\n\n## Security boundary\n\nThe browser uses only public endpoints:\n\n- GET /public/xparallel/access\n- GET /public/health\n- GET /public/solutions\n- POST /public/solution\n- POST /public/verify\n- POST /public/graph/search\n\nNo XP_TOKEN, approval token, payment credential, bank credential or other secret is placed in browser code.\n\nReal execution remains server-side and human-approval gated. Payment capture remains disabled.\n\n## Architecture\n\nAxaliai → XParallel Gateway → XParallel Workspace → Sandbox → Evidence → Human Approval → Deploy
