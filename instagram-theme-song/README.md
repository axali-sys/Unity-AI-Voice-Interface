# ThemeSong IG — standalone prototype

A minimal prototype for an owner-selected theme song experience associated with an Instagram account.

## Current MVP
- Instagram connection placeholder
- Owner handle and track selection
- Playback behavior selection
- Profile preview
- Local save
- Explicit Meta integration boundary

## Deployment
The prototype is intentionally framework-free HTML/CSS/JS, so it can be deployed from the `instagram-theme-song` directory as a static Vercel project. GitHub remains the source of truth.

## Next integration phase
Add Meta OAuth and only the Instagram capabilities supported by Meta's current APIs and App Review. Do not assume an external web app can inject or autoplay audio inside the Instagram client.
