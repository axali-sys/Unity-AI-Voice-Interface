Authenticated repair-job API

Use a bearer token from an authorized server-side client. Never embed XP_TOKEN in browser code.

POST
/repair/jobs
Submit a diagnostic or repair plan. JSON: {"query":"...","job_type":"diagnostic","workspace_id":"..."}. Returns a job ID and plan-only result.
GET
/repair/jobs?workspace_id=...
List repair jobs scoped to the requested authorized workspace.
GET
/repair/jobs/{job_id}?workspace_id=...
Retrieve a job's status, result, timestamps, and verification evidence.

These repair endpoints create and retrieve plans only. They do not inspect a remote repository, run tests against a target, change files, or execute repairs. Those capabilities require separate adapters and approval-gated workflows. Private endpoints, including execution, are not exposed as browser controls.

Infrastructure boundaries
